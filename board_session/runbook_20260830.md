## Phase 1 — Capture (09:20-10:00, 40 min)

```bash

    -n 5000 -o Dataset/run_hw_sca.h5 --gain <G> --crypto-mhz 10.0 \
```

## Phase 2 — Offline training (10:00-10:50, 50 min; this box)

```bash
# 5. Preprocess: --auto-center is REQUIRED (new core shifts leakage location). Note printed offset.
.venv/bin/python training/preprocess.py Dataset/run_hw_sca.h5 --auto-center
#    -> training/data/run_hw_sca.npz

# 6. LDA edge gate: EDGE > 0.01 nats across cols -> proceed. ~0 -> leakage absent, fix gain/trigger before attacking.
.venv/bin/python training/template_edge.py --h5 Dataset/run_hw_sca.h5 --n 2000 --fit-k 1500

# 7. S-box profile (single column): gate is val acc >> chance (16.7%).
.venv/bin/python training/train.py training/data/run_hw_sca.npz --target sbox --column 0 --arch cnn1
#    -> training/models/run_hw_sca_c0_sbox_cnn1.pt

# 8. KADD profiles for kadd_acppa (optional, ~3 min each; run in background during Phase 3 start):
.venv/bin/python training/train.py training/data/run_hw_sca.npz --target kadd --column 0 --arch mlp
#    ... repeat column 1..7
#    -> training/models/run_hw_sca_c{i}_kadd_mlp.pt
```

## Phase 3 — Attack (10:50-12:00, 70 min; board host)

```bash
# 9. Single-column proof (2 key bits of column 0). Expect convergence to the true hyp (key 00010203...):
python3 training/adaptive.py --attack \
    --npz training/data/run_hw_sca.npz \
    --model training/models/run_hw_sca_c0_sbox_cnn1.pt \
    --column 0 --key 000102030405060708090a0b0c0d0e0f \
    --gain <G> --offset <printed-offset> \
    --bitstream vivado_ascon/ascon_cw305_top.bit
#    (--M 64 nonce-repetition averaging is the documented SNR lever q15->q9.)

# 10. FULL-KEY crack, no extra training: LDA template evidence + transformer integration, fresh random keys,
#     oracle-labeled replay, verify_key PASS == key cracked.
python3 training/live_loop_transformer.py \
    --evidence template --profile-h5 Dataset/run_hw_sca.h5 \
    --bitstream vivado_ascon/ascon_cw305_top.bit \
    --gain <G> --episodes 50 --max-queries 60

# 11. KADD beam search (only if step 8 ran): full 16-byte key, 8 profiles.
python3 training/kadd_acppa.py --attack \
    --npz training/data/run_hw_sca.npz \
    --models 'training/models/run_hw_sca_c%i_kadd_mlp.pt' \
    --key 000102030405060708090a0b0c0d0e0f \
    --gain <G> --offset <printed-offset> --max-queries 300
```

## Cost/risk notes
- verify_state lane-order failure eats the whole buffer (rebuild 25-45 min). Do NOT capture before it passes.
- adaptive.py/kadd_acppa.py gain/offset defaults are STALE (old masked core: -2/700). Always pass --gain <G> --offset <auto-center>.
- kadd_acppa --models is a printf format over 8 columns (c%i), needs --offset too (default 700 breaks it).
- Escape '%' correctly on the board: wrap --models arg in single quotes.
- If edge gate (step 6) fails: recheck gain / trigger / verify_state, don't burn attack time.
